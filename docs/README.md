# Sunborn Documentation (`docs/`)

Technical specifications, research papers, architectural designs, launch audit registers, and operational runbooks for Sunborn.

## Structure

- **`architecture/`**: High-level system architecture, component interaction diagrams, and data flow specifications.
- **`audit/`**: Comprehensive FAANG architectural audit registers, defect ledgers, and GitHub issues tracking.
- **`launch/`**: Launch readiness checklists, security disclosures, and operational runbooks.
- **`research/`**: Research papers, mathematical formulations of non-exchangeable conformal risk control, and PCSR specifications.
- **`STATUS.md`**: Authoritative release status, governance baseline, and staging criteria.
