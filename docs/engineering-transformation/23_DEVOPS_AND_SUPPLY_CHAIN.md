# DevOps, Container Hardening & Software Supply Chain Audit

**Container Base:** Distroless / Debian Bookworm Non-Root  
**Container User:** `USER nonroot:nonroot` (UID 65532, GID 65532)  
**Security Context:** `readOnlyRootFilesystem: true`, `drop: [ALL]`  
**SBOM Standard:** CycloneDX 1.5 JSON (`sbom.cyclonedx.json`)  
**Vulnerability Scanner:** `cargo-audit` (Zero Known Vulnerabilities)  

---

## 1. Container Hardening Specification

```dockerfile
# Hardened multi-stage build (.devcontainer/Dockerfile)
FROM rust:1.96-bookworm as builder
WORKDIR /workspace
COPY . .
RUN cargo build --release -p sunborn-gateway

FROM gcr.io/distroless/cc-debian12:nonroot
COPY --from=builder /workspace/target/release/sunborn-gateway /usr/local/bin/
USER nonroot:nonroot
EXPOSE 8080
ENTRYPOINT ["/usr/local/bin/sunborn-gateway"]
```
