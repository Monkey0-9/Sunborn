# Release Acceptance Evidence — 2026-11-25

This file records a **local** release-acceptance run on the review host. It does not
close Issues #21 or #23: the host is not an independent clean Windows 11 image, and the
code-signing certificate used here is self-signed and untrusted.

## Environment

- OS: Microsoft Windows NT 10.0.26300.0 (Windows 11, release 26H2)
- Binary: `sunborn-gateway 1.0.0 (release)`
- Package: `target/dist/sunborn-desktop-v1.0.0-windows-x64.zip`
- Package SHA-256: `9d45500212cf329cc2ec507f95b509bd3e974c4a1f37ff8fedaf35c74ace6a13`
  (`target/dist/SHA256SUMS.txt` was regenerated by the packaging script)
- Payload: 7.24 MB, self-contained, no Rust/Node required on the target

## 1. Clean-toolchain install

The extracted package was installed with only Windows system directories on `PATH`:

```powershell
$env:PATH = 'C:\Windows\System32;C:\Windows'
Get-Command cargo   # not found
Get-Command node    # not found
& install-sunborn.ps1 -TargetDir <temp> -Silent
& <temp>\bin\sunborn-gateway.exe --version
```

Result: installer exit 0, smoke test passed (`gateway answered /health on
127.0.0.1:18081`), and version output was `sunborn-gateway 1.0.0 (release)`.

**Defect found and fixed during this run:** the installer smoke test inherited the
gateway's broker defaults (`redis://dragonfly:6379`) and failed on a machine without
Dragonfly. `scripts/install-sunborn.ps1` now sets memory cache/DB/vector backends,
`SUNBORN_STRICT_DURABILITY=false`, and `SUNBORN_KMS_PROVIDER=local-aead` for the smoke
run, matching `scripts/sunborn-desktop.ps1`.

## 2. Uninstall

```powershell
& <temp>\uninstall.ps1 -TargetDir <temp> -Silent -PurgeData
Test-Path <temp>                                  # False
Get-Process -Name sunborn-gateway                 # none
```

**Defect found and fixed during this run:** the uninstaller ignored `-TargetDir` and
always targeted `%LOCALAPPDATA%\Sunborn`. It now accepts `-TargetDir`, and the registry
`UninstallString` / `QuietUninstallString` pass the install directory through.

## 3. Authenticode signing

A self-signed code-signing certificate was generated for pipeline verification only:

- Subject: `CN=Sunborn Dev Self-Signed (NOT FOR PRODUCTION)`
- Thumbprint: `3C8F48D0CEC89CF69EBE57F6F64F3D45B003B092`
- Validity: 30 days
- Timestamp: omitted (`-NoTimestamp`), because the default RFC 3161 authority was
  unreachable and blocked the packaging script

`Get-AuthenticodeSignature` on the packaged binary:

```
Status  : UnknownError
Message : A certificate chain processed, but terminated in a root certificate
          which is not trusted by the trust provider.
Subject : CN=Sunborn Dev Self-Signed (NOT FOR PRODUCTION)
```

This proves the signing path applies a real Authenticode signature, but it is **not** a
trusted release signature and must not be presented as one.

**Defect found and fixed during this run:** `Get-PfxCertificate` prompts interactively
for a password-protected PFX and blocks unattended runs. The script now loads the PFX via
`X509Certificate2` with `SIGNING_CERT_PASSWORD`, fails if no signer certificate is
applied, and supports `-NoTimestamp` for offline/air-gapped signing.
