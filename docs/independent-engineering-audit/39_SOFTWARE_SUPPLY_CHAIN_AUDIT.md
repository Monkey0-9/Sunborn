# 39 — Software Supply Chain Audit

---

## 1. Dependencies

- Rust: workspace deps pinned via `Cargo.lock` (355+ crates). `sqlx`, `redis`, `aws-sdk-kms`, `aes-gcm`, `roaring`, `dashmap`, `axum`, `tokio`.
- Frontend: npm; `package-lock.json` present (pnpm lock ignored).
- Python: zero runtime deps (stdlib `urllib`); dev uses `uv`.
- No vendoring; no dependency pinning policy beyond lockfiles.

## 2. Vulnerability management

| Control | Status |
|---|---|
| `cargo audit` in CI | YES |
| Suppressed advisories | `audit.toml` ignores **RUSTSEC-2026-0459** and **RUSTSEC-2023-0071** |
| Docs claim | "0 vulnerabilities across 355 crates (remediated RUSTSEC-2026-0459)" — **contradicted** by audit.toml |
| npm audit | YES but `--omit=dev` |
| Container scan | **NONE** (no Trivy/Grype) |
| CodeQL / SAST | Semgrep only, deprecated action |
| Secret scan | trufflehog `--only-verified` |

## 3. SBOM

- `sbom.cyclonedx.json` tracked and generated by `scripts/generate_sbom.py`.
- Generator is **non-deterministic** (random UUID + timestamp), has no dependency graph, no hashes, no licenses, no dev deps.
- Not generated in CI as an artifact.

## 4. Signing / provenance

| Control | Status |
|---|---|
| Image signing (cosign) | **NONE** |
| SLSA attestation | **NONE** (docs claim Level 3) |
| Build provenance | buildx `provenance: mode=max` in release only |
| Digest pinning | not fed back into chart |
| Reproducible builds | not established (`--locked` not used) |

## 5. License compliance

- `scripts/audit_licenses.py` is **cosmetic**: it reads `name =` lines from Cargo.lock and never reads a license; `PERMITTED_LICENSES` is unused.
- Root `LICENSE` is Apache-2.0; `Cargo.toml` license Apache-2.0.

## 6. CI/CD permissions

- Workflows use default token permissions (no explicit least-privilege `permissions:` block in reviewed files).
- `release.yml` has a `release-approval` environment (good).

## 7. Verdict

Supply chain: **WEAK**. Real audit tools exist but advisories are suppressed, SBOM is cosmetic, no signing/SLSA, and no container scanning. Score: **3/10**.
