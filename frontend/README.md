# Sunborn Admin Cockpit (`frontend/`)

Modern, high-performance administrative cockpit and live observability dashboard for Sunborn.

## Features

- **Real-Time Mesh Topology**: Live cluster node status, latency percentiles, and circuit-breaker telemetry.
- **FinOps Spending Visualizer**: Interactive spend ledger, tenant ceilings, and token-cost savings graphs.
- **BFF (Backend-for-Frontend)**: Secure API gateway with CSRF protection, session management, and WCAG 2.2 AA accessibility.

## Development & Testing

```bash
npm install --prefix frontend
npm test --prefix frontend
npm run build --prefix frontend
```
